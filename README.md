# Loyverse Digital Menu

منصة قائمة رقمية متصلة مع **Loyverse POS** — عرض القائمة للعميل فقط + لوحة تحكم قوية مستوحاة من MenuTiger.

## المميزات

### للعميل (Public Menu)
- قائمة رقمية جميلة ومتجاوبة (موبايل أولاً)
- أقسام قابلة للتنقل + بحث
- عرض الصور والأسعار والوصف
- رابط `/menu/[slug]` جاهز للـ QR
- بدون طلب أونلاين (عرض فقط)

### لوحة التحكم
- إدارة المتاجر والتكاملات
- مزامنة Categories + Items + Modifiers من Loyverse
- تصميم مستوحى من MenuTiger

## التقنيات

- Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · Loyverse API

## التشغيل

```bash
npm install
npm run dev
```

### تدفق العمل
1. `/integrations` — Access Token
2. `/stores` — أضف متجراً بـ slug
3. `/menus` — مزامنة الآن
4. `/menu/your-slug` — معاينة القائمة للعميل

> حالياً البيانات في localStorage (نفس المتصفح). المرحلة 6 ستنقل التخزين لقاعدة بيانات ليظهر للعملاء من أي جهاز.
